# AlgoAtlas · OJ 题迹

把洛谷、Codeforces、AtCoder 的已通过题目收进同一张个人题迹地图，在本地直接运行。

## 已实现

- 输入洛谷用户名 / UID、Codeforces Handle、AtCoder 用户名后自动同步
- **明暗主题**：顶栏太阳 / 月亮按钮切换，首次访问跟随系统，手动选择会保存在本地
- **同一平台支持多个账号**：主号和小号可一起追踪，题迹自动合并去重
- 单个账号失败不会影响其他账号；部分失败会保留成功数据并给出提示
- 账号保存在浏览器 `localStorage`，下次打开自动读取，不保存密码
- 账号管理支持添加、移除多个 Handle；旧版单账号配置会自动迁移
- **总览**：三站去重通过数、Rating、AC 热力图、难度构成环形图、最近通过
- **可视化**：Codeforces 有完整的 Rating 分段条形表；洛谷 / AtCoder 有难度环形图与分段条形图
- **比赛题库（CF / AtCoder）**：参照 CFTracker Contests 与 AtCoder Problems Table 做比赛矩阵
  - 每行是一场比赛，列是 A、B、C… 题；整份题单一眼看完
  - 点击比赛名进入比赛主页，点击题目标题直接跳转原题
  - 单元格背景色直接表示状态：绿色已通过、橙色尝试过、白色未做
  - 按比赛名 / ID 搜索，按 Div.1、Div.2、ABC、ARC、AGC、AHC 等类别筛选
  - 支持隐藏已完成比赛、分页浏览
- **洛谷主题库**：洛谷不按比赛归档，直接读取公共主题库
  - 支持题号 / 题目名搜索、题目类型（P / B / CF / AT / SP / UVA）和 8 级难度筛选
  - 已通过题目整行绿色标记，题目名称可跳转洛谷原题
  - 服务端按页读取，避免一次性拉取 18,000+ 道题
- **洛谷登录 Cookie**：可选
  - 在洛谷页面点「Cookie」粘贴登录态，以自己的账号身份读取练习数据
  - Cookie 只发送到本机服务并保存在内存中，重启服务后重新填写
- **手动补题**：洛谷 / Codeforces / AtCoder 均可手动添加已做题目
  - 记录保存在浏览器本地，可随时在「补题」弹窗中撤销
  - 与自动同步数据合并并去重，不会重复计数
- **洛谷**：按新版 8 级难度归档，红、橙、黄、绿、青、蓝、紫、黑原生配色
- **Codeforces**：按比赛归档，并提供 **Rating 分段明细表**
  - 每 100 分一档，2400 以上单独拆成 11 档
  - 包含题目数、占比、平均值、最高值
- **AtCoder**：按比赛归档，题目前显示 Difficulty
- 全站支持搜索、难度筛选、排序、分页加载
- 所有题目、比赛均支持点击跳转原站
- 响应式布局，支持手机浏览
- 服务端内存缓存：用户数据 10 分钟，题库静态数据 6 小时；手动刷新可绕过用户缓存

## 在线部署

项目已经配置好 Vercel 全栈部署：

- 前端构建：`dist/`
- API：`api/proxy.js`（Express serverless 入口）
- 配置：`vercel.json`

一键导入：

<https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FBilllIlllly%2Falgoatlas>

在 Vercel 用 GitHub 登录并点击 Deploy 即可。部署后的前端和 API 同域，不需要额外配置环境变量。

## 本地运行

```bash
npm install
npm run build
npm start
```

打开 <http://127.0.0.1:4318>。

开发模式：

```bash
npm run dev
```

Vite 页面在 <http://127.0.0.1:5173>，同时启动 4318 端口的 API 服务。

## 数据来源

- 洛谷：公开用户练习页 + 用户搜索接口
- Codeforces：官方公开 API
- AtCoder：AtCoder Problems / kenkoooo 资源与提交接口、AtCoder 公开 Rating History

## 已知限制

- 洛谷用户隐藏练习情况时，在页面配置该账号的登录 Cookie 后读取。
- 合并统计按题目去重，同一道题被多个账号通过时只计一次。
- 洛谷没有公开 AC 时间，因此热力图只统计 Codeforces 与 AtCoder。
- 洛谷主题库通过公开列表接口按页读取，筛选由服务端完成。
- 最新比赛的部分题目可能还没有评定难度，显示为「未定」。
- Codeforces 官方 API 有调用频率限制，多账号首次同步会依次请求，可能稍慢；之后会命中缓存。
- 手动补题只记录在浏览器本地，不会写回 OJ；清理浏览器数据会一并丢失。
- 手动补题默认不虚构 AC 日期，因此不会进入按 AC 时间统计的热力图。
- 当前是本地版本，账号配置保存在浏览器，没有云端同步。
